## 🎬 AutoDubVN

### Automated Vietnamese Video Dubbing Pipeline

[![AutoDubVN](https://img.shields.io/badge/OPEN_PROJECT-AutoDubVN-00BFFF?style=for-the-badge\&logo=github\&logoColor=white)](https://github.com/Crazyscholarr/AutoDubVN)

<br><br>

[![Stars](https://img.shields.io/github/stars/Crazyscholarr/AutoDubVN?style=flat-square\&logo=github)](https://github.com/Crazyscholarr/AutoDubVN/stargazers)
[![Last Commit](https://img.shields.io/github/last-commit/Crazyscholarr/AutoDubVN?style=flat-square\&logo=git)](https://github.com/Crazyscholarr/AutoDubVN/commits/main)
[![Repo Size](https://img.shields.io/github/repo-size/Crazyscholarr/AutoDubVN?style=flat-square)](https://github.com/Crazyscholarr/AutoDubVN)

</div>

> **AutoDubVN** is an automated video processing and Vietnamese dubbing toolkit built primarily with Python.
>
> It combines speech recognition, translation, TTS, subtitle processing, speaker diarization and GPU-accelerated video rendering into a single workflow.

### ✨ Main Features

* 🎙️ Automatic Speech Recognition
* 🌐 Vietnamese Translation Pipeline
* 👥 Speaker Diarization
* 🗣️ Text-to-Speech
* 📖 Story Voice & Story Writer
* 📝 Subtitle Processing
* ⏱️ Timeline Synchronization
* 🎵 Background Music Processing
* 🖼️ Slideshow Generation
* 🎬 Automated Video Rendering
* ⚡ NVIDIA NVENC Hardware Encoding
* 🖥️ Desktop GUI
* 🌐 Web UI
* 🔌 Local HTTP API
* 🧪 Automated Tests
