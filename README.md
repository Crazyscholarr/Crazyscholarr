# 🚀 Featured Project

## 🎬 AutoDubVN

### Automated Vietnamese Video Dubbing Pipeline

[![AutoDubVN](https://img.shields.io/badge/OPEN_PROJECT-AutoDubVN-00D4FF?style=for-the-badge\&logo=github\&logoColor=white)](https://github.com/Crazyscholarr/AutoDubVN)

</div>

> **AutoDubVN** is an automated video processing and Vietnamese dubbing toolkit built with Python.
>
> It combines speech recognition, translation, TTS, subtitle processing, speaker handling and GPU-accelerated video rendering into one workflow.

### ✨ Main Features

* 🎙️ Automatic Speech Recognition
* 🌐 Vietnamese Translation Pipeline
* 👥 Speaker Diarization
* 🗣️ Text-to-Speech & Story Voice
* 📝 Subtitle Processing
* ⏱️ Timeline Synchronization
* 🎵 Background Music Processing
* 🖼️ Slideshow Generation
* 🎬 Automated Video Rendering
* ⚡ NVIDIA NVENC Hardware Encoding
* 🖥️ Desktop & Web GUI
* 🔌 Local HTTP API
* 🧪 Automated Tests
