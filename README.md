## 🎬 AutoDubVN

### Quy trình tự động lồng tiếng video sang tiếng Việt

[![AutoDubVN](https://img.shields.io/badge/OPEN_PROJECT-AutoDubVN-00BFFF?style=for-the-badge&logo=github&logoColor=white)](https://github.com/Crazyscholarr/AutoDubVN)

[![Last Commit](https://img.shields.io/github/last-commit/Crazyscholarr/AutoDubVN?style=flat-square&logo=git)](https://github.com/Crazyscholarr/AutoDubVN/commits/main)

> **AutoDubVN** là bộ công cụ xử lý video và tự động lồng tiếng Việt được xây dựng chủ yếu bằng Python.
>
> Nó kết hợp nhận dạng giọng nói, dịch thuật, TTS, xử lý phụ đề, phân biệt người nói và kết xuất video bằng GPU thành một quy trình làm việc duy nhất.

### ✨ Tính năng chính

- 🎙️ Nhận dạng giọng nói tự động
- 🌐 Dịch nội dung sang tiếng Việt
- 👥 Speaker Diarization
- 🗣️ Text-to-Speech
- 📖 Story Voice / Story Writer
- 📝 Xử lý phụ đề SRT
- ⏱️ Đồng bộ timeline
- 🎵 Xử lý nhạc nền
- 🖼️ Tạo slideshow
- 🎬 Kết xuất video tự động
- ⚡ NVIDIA NVENC Hardware Encoding
- 🖥️ Desktop GUI
- 🌐 Web UI
- 🔌 Local HTTP API
- 🧪 Automated Tests
